# FCA Bot – Render + n8n Docker Telegram Integration

**FCA Bot** is a workflow automation project using [n8n](https://n8n.io/) deployed on [Render](https://render.com) to connect Telegram with GapGPT Vision API.  
The bot processes FCA project phase photos, generates professional captions, and posts them to the Telegram channel **@Pro_FCA**.
